Human-Robot Teaming

Project ID: HK-2  |  Color: RED

Course: Senior Project 4850 Section 2 – Fall Semester 2025

Large Language Models (LLMs) are utilized in various domains to complete multiple tasks. In this project, we develop and evaluate a modular framework that uses an LLM to convert natural-language task descriptions into robot-executable action plans for collaborative human-robot teams. Using Webots' Simulation and Hugging Face's LLMs, we've design a robot-agnostic JSON action schema to support portable, simulation-ready action plans.
